# Демеу · Қырқынан шығару

Сайт-приглашение. Все данные (дата, ресторан, адрес, WhatsApp, музыка) — в объекте `CONFIG` в начале `<script>` в `index.html`.

- Персональная ссылка: `https://<user>.github.io/<repo>/?g=Айгүл%20апа`
- Русская версия по умолчанию: `?lang=ru`
- Музыка: положите `assets/music.mp3` и укажите `music: 'assets/music.mp3'`

GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.
