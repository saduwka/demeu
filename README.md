# Демеу · Қырқынан шығару

Сайт-приглашение. Все данные (дата, ресторан, адрес, ссылка на форму, музыка) — в объекте `CONFIG` в начале `<script>` в `index.html`.

- Персональная ссылка: `https://<user>.github.io/<repo>/?g=Айгүл%20апа`
- Русская версия по умолчанию: `?lang=ru`
- Музыка: положите `assets/music.mp3` и укажите `music: 'assets/music.mp3'`

## Ответы гостей → Google Таблица
1. Откройте таблицу «Демеу — қонақтар (RSVP)» → Расширения → Apps Script.
2. Удалите всё в `Code.gs` и вставьте код из `apps-script/Code.gs`. Сохраните.
3. Развернуть → Новое развертывание → тип «Веб-приложение».
   - Выполнять от имени: **Я**
   - У кого есть доступ: **Все**
4. Разрешите доступ (Дополнительные настройки → Перейти к проекту → Разрешить).
5. Скопируйте URL вида `https://script.google.com/macros/s/…/exec` и вставьте в `CONFIG.rsvpUrl`.

При изменении кода скрипта: Развернуть → Управление развертываниями → ✎ → Версия: новая → Развернуть (URL останется тем же).
